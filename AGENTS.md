# agent-dash: agent rules

- **Merge your own PRs here at once.** This repo (`pgragg/agent-dash`) is Piper's personal tool, and no one reviews it. After you open a PR into `main` and the checks pass (`pnpm typecheck && pnpm test && pnpm build`), merge it yourself with `gh pr merge <n> --merge`, then `git push origin --delete <branch>` (`--delete-branch` fails when `main` is checked out in another worktree). Do not wait for a review, do not run polish-pr, and do not ask first. This overrides the global "ask before merges" rule, for this repo only.
- **The live dashboard (port 7777) runs from `~/02_programming/agent-dash`, on `main`.** That folder holds the repo's `.git`, so every worktree depends on it. Do not check out another branch there, do not commit there, and never move or delete it. To ship a change to it: merge the PR, then `git pull --ff-only && pnpm build` in that folder, and restart the server. The headless agents survive a restart.
- **Use a `git worktree` for each change. Never make a new clone of this repo**: a clone hides its work from the other checkouts. From `~/02_programming/agent-dash`, run `git worktree add -b <branch> ../agent-dash-<topic> origin/main`, then `pnpm install`. A test server in a worktree needs its own port (`AGENT_DASH_PORT=77xx`). It reads Piper's settings from the main checkout's gitignored `agent-dash.config.json` by itself, read-only. After the PR merges, run `git worktree remove ../agent-dash-<topic>`.
