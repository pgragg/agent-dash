# agent-dash: agent rules

- **Merge your own PRs here at once.** This repo (`pgragg/agent-dash`) is Piper's personal tool, and no one reviews it. After you open a PR into `main` and the CI checks pass (`gh pr checks <n> --watch`: build and tests, gitleaks, `pnpm audit`, actionlint, and a home-path check), merge it yourself with `scripts/ship.sh <n>` (it runs `gh pr merge <n> --merge --admin`, then `git push origin --delete <branch>`, because `--delete-branch` fails when `main` is checked out in another worktree, then ships). Do not wait for a review, do not run polish-pr, and do not ask first. This overrides the global "ask before merges" rule, for this repo only. `main` requires one approving review, so a merge without `--admin` fails. `--admin` also skips the required checks, so never merge while a check is red. The GitHub user `pgragg` (Piper) is allowed to merge with `--admin` into agent-dash. Delete the branch only after the merge succeeds: a deleted branch closes its open PR.
- **The live dashboard (port 7777) runs from `~/02_programming/agent-dash`, on `main`.** That folder holds the repo's `.git`, so every worktree depends on it. Do not check out another branch there, do not commit there, and never move or delete it. To ship a change to it, run `scripts/ship.sh <pr>` from any worktree. It merges the PR when its checks are green, pulls `main` into that folder, checks that the merge commit is there, builds, restarts the server, and checks the served page. It stops at the first failed step. Do not do these steps by hand: a blocked merge followed by a build once shipped the old `main`. The headless agents survive a restart.
- **Use a `git worktree` for each change. Never make a new clone of this repo**: a clone hides its work from the other checkouts. From `~/02_programming/agent-dash`, run `git worktree add -b <branch> ../agent-dash-<topic> origin/main`, then `pnpm install`. A test server in a worktree needs its own port (`AGENT_DASH_PORT=77xx`). It reads Piper's settings from the main checkout's gitignored `agent-dash.config.json` by itself, read-only. After the PR merges, run `git worktree remove ../agent-dash-<topic>`.
